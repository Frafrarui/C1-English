# Preposiciones C1

App de estudio para las preposiciones dependientes del C1.

## Cómo ejecutarlo

### Opción A — Con Node.js (recomendado)

1. Instala las dependencias:
   ```
   npm install
   ```

2. Arranca el servidor:
   ```
   npm start
   ```

3. Abre en el navegador:
   ```
   http://localhost:3000
   ```

### Opción B — Sin instalar nada

Abre directamente el archivo `public/index.html` en cualquier navegador.
No necesita servidor.

---

## Contenido

- **Repaso** — todos los grupos organizados por preposición con notas sobre los pares conflictivos
- **Flashcards** — palabra → preposición, con filtros por categoría
- **Test** — frases completas con hueco, 4 opciones, explicación al fallar

## Qué se ha corregido respecto a la versión anterior

- Cada frase del test tiene `___` exactamente donde va la preposición (no al revés)
- Las expresiones fijas como `out of breath`, `under pressure` etc. se preguntan correctamente
- La explicación azul es específica de la tarjeta que acabas de fallar (no genérica)
- `elaborate on` y otros verbos con preposición fija están verificados uno por uno
